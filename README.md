# **Amtrak Performance Analysis** 🚄📊  

## **Overview**  
This project analyzes **Amtrak's performance metrics** using data science and business analytics techniques. By leveraging **Python, SQL, and data visualization tools**, this project provides insights into **train delays, on-time performance, and other key operational metrics**.  

## **Objectives**  
- Evaluate **Amtrak's train performance** across different routes.  
- Identify **trends and patterns** in delays.  
- Develop **interactive visualizations** for better insights.  
- Provide **data-driven recommendations** for operational efficiency.  

## **Technologies Used**  
- **Python** (Pandas, NumPy, Matplotlib, Seaborn)  
- **SQL** (for data extraction and transformation)  
- **Jupyter Notebook**  
- **Power BI / Tableau** (for interactive dashboards)  

## **Dataset**  
The dataset includes **Amtrak train performance data**, consisting of:  
- **Train schedules** (arrival & departure times)  
- **Delay reasons & durations**  
- **Weather and external factors** affecting performance  
- **Route-specific performance trends**  

## **Key Features**  
✔ **Data Cleaning & Preprocessing** – Handling missing values and transforming raw data.  
✔ **Exploratory Data Analysis (EDA)** – Visualizing trends and patterns in train delays.  
✔ **SQL Querying** – Extracting insights from large datasets efficiently.  
✔ **Dashboard Creation** – Interactive visualizations for decision-making.  
✔ **Predictive Modeling** *(if applicable)* – Using ML to forecast delays.
